# VN PC — відеоредактор для Windows (етап 1)

## Як зібрати .exe (без встановлення чого-небудь на ноутбук)

1. Створи новий репозиторій на GitHub і завантаж туди **весь вміст** цієї папки
   (разом з прихованою папкою `.github`).
2. Відкрий вкладку **Actions** → **Build VN PC** → **Run workflow**
   (або воно запуститься саме після завантаження файлів).
3. Коли збірка зеленa, відкрий її та внизу в **Artifacts** завантаж **VNPC-Windows**.
4. Розпакуй архів у будь-яку папку і запусти **VNPC.exe**
   (ffmpeg.exe та ffprobe.exe вже лежать поруч — нічого ставити не треба).

## Що вміє (етап 1)

- Імпорт відео (кнопка або перетягування файлів у вікно)
- **Проксі для плавного перегляду**: при імпорті автоматично створюється легка копія 540p,
  перегляд іде з неї, експорт — з оригіналів у повній якості
- Магнітна доріжка: розрізати, видалити, переставити, обрізати краї мишею
- Швидкість кліпа (0.25x–4x) і гучність (0–200%)
- Формат кадру: 16:9, 9:16, 1:1, 4:5, 4:3
- Експорт MP4 (480p / 720p / 1080p), з апаратним кодуванням Intel QSV
  (якщо не спрацює — автоматично програмне)

## Гарячі клавіші

| Клавіша | Дія |
|---|---|
| Пробіл | Грати / пауза |
| S | Розрізати в місці курсора |
| Delete | Видалити вибраний кліп |
| ← / → | Кадр назад / вперед (з Shift — 1 секунда) |
| Home | На початок |

Проксі-файли лежать у `%LOCALAPPDATA%\VNPC\proxy` — їх можна безпечно видаляти.
